# Examples

## Synthetic run

```bash
sensebench synth examples/out --duration 600 --rate 100 --seed 0
```

Writes a Formula-Student-style run, generated by `sensebench.synthetic`:

- `run.csv`: wide CSV the way many data loggers write it. A `time_s` column (relative clock), one column per signal. Slow signals (GPS, motor temperature, battery voltage, 10 Hz) are blank between their samples.
- `ground_truth.json`: units and rates for every channel, plus each injected fault with its exact interval:

| Fault | Channels | What a rule should catch |
|---|---|---|
| `overheat` | `motor_temp_c` | cooling failure; temperature above 80 °C |
| `dropout` | `brake_pressure_bar` | sensor goes silent for 3 s |
| `sensor_mismatch` | `wheel_speed_kmh`, `gps_speed_kmh` | wheel speed reads 20% high for 15 s |
| `spike` | `brake_pressure_bar` | +80 bar spike for 50 ms |

The same seed always gives an identical run. `examples/out/` is git-ignored; regenerate it as needed.

Sample alert rules will live in `examples/rules/` (M3).
